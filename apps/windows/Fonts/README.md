# Bundled terminal font

`JetBrainsMonoNerdFontMono-Regular.ttf` is JetBrainsMono Nerd Font Mono from
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) (JetBrains Mono patched with Powerline, box-drawing and
icon glyphs at single cell width), the same file the other apps bundle (`assets/fonts/`). Licence: SIL Open
Font License 1.1 (`OFL.txt`, shipped next to the font). Unmodified. It has programming ligatures, which the
Ligatures setting turns on and off.

Bold is synthesised from it (the Bold file would add 2.4 MB).
