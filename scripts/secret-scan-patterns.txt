# Patterns for scripts/secret-scan.sh: a name, one TAB, then an extended regular expression,
# matched against one line of text. Only unambiguous formats belong here: on 2026-11-12, broad
# patterns ("password = ...", "user:pass@") matched 44 harmless lines in this repository for every
# real hit. gitleaks covers those cases when it is installed.
private key block	^[[:space:]]*-----BEGIN ([A-Z0-9]+ )*PRIVATE KEY( BLOCK)?-----[[:space:]]*$
