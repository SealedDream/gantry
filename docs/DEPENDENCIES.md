# Dependency policy, accepted advisories and notices

There is no CI, so these checks run in the release process: `scripts/release.sh` runs
`scripts/release-checks.sh` before it signs anything (skipped only with `--dry-run`). Run it by hand
after any `Cargo.lock` or `package-lock.json` change. Reviewed 2026-11-05 (Codex D01–D04, L04).
Tools: `cargo install cargo-audit cargo-deny --locked`; Python 3; npm.

| Check | Command | Fails on |
|---|---|---|
| RustSec vulnerabilities, every shipped lockfile | `sh scripts/audit-deps.sh` | a vulnerability not in `scripts/audit-ignore.txt` |
| Licences, sources, advisories incl. unmaintained | `sh scripts/deny.sh` (`deny.toml`) | a licence not allowed, a registry or git source not allowed, an advisory not ignored, a wildcard version |
| npm advisories (Tauri frontend) | `sh scripts/audit-npm.sh` | an advisory not in `scripts/audit-npm-ignore.txt`; also reports ignores that are no longer needed |
| Third-party notices | `python3 scripts/notices.py --check` | a committed `licenses/*/THIRD_PARTY_NOTICES.txt` that no longer matches the lockfiles, or a package with no licence at all |
| SBOM | `sh scripts/sbom.sh` | — (writes `build/sbom/*.cdx.json`) |

`deny.toml` only looks at the shipped targets (macOS arm64/x64, Windows x64), so Linux-only GTK/zbus
crates and their maintenance notices are out of scope.

## Licences and notices

`deny.toml` allows permissive licences plus MPL-2.0 (file-level copyleft: the crates are used
unmodified and their notices ship). Adding a licence needs a reason in the PR.

An allow-list is not the distribution artefact: each bundle ships a notices file generated by
`scripts/notices.py` from the crates actually linked into it (normal dependencies for its targets,
no proc-macros or build-only crates) and, for Tauri, the production npm packages:

| Artifact | File | Copied by |
|---|---|---|
| Native Mac | `licenses/native-mac/THIRD_PARTY_NOTICES.txt` | `apps/macos/bundle.sh` → `Contents/Resources/` |
| Native Win | `licenses/native-win/THIRD_PARTY_NOTICES.txt` | `apps/windows/BastionShell.csproj` → next to `Gantry.exe` |
| Tauri Mac / Win | `licenses/tauri/THIRD_PARTY_NOTICES.txt` | `ui-tauri/src-tauri/tauri.bundle.json` `resources` |

The files are committed (the Windows build host has no Python) and `--check` keeps them current.
Where a crate offers `… OR MIT`, Gantry elects MIT and ships that text plus any NOTICE files.
Packages that ship no licence file are listed by SPDX id at the end of each file. The bundled font's
OFL text is included. OpenH264 is not bundled: when RDP needs it, Gantry downloads Cisco's binary,
which Cisco licenses under its own terms.
