# Gantry 1.0.0 (draft)

First public release of Gantry Native for macOS and Windows.

## Downloads

| File | For |
|---|---|
| `Gantry-macos-arm64.dmg`, `.zip` | macOS 14 or later, Apple silicon. `Gantry.app` + `plugins/` (the dmg has an Applications link) |
| `Gantry-1.0.0-windows-x64-setup.exe` | Windows installer (Inno Setup, per user, no admin) |
| `install.ps1` | PowerShell installer: `irm .../releases/latest/download/install.ps1 \| iex` |
| `Gantry-windows-x64.zip` | Windows 10 and 11, x64. `Gantry.exe` + `plugins/` |
| `SHA256SUMS` | checksums of every archive |
| `update-manifest.json` | signed manifest used by Check for Updates |

Builds are unsigned (no paid certificate). First launch: see the README, "First launch".

## What is in it

- SSH terminal: strict host keys, jump hosts, agent, host certificates, split panes, broadcast, snippets, session logs, tmux attach, Mosh.
- RDP, VNC and web in tabs.
- SFTP browser with transfer queue; SCP and FTPS.
- Saved local, remote and SOCKS tunnels.
- Encrypted credentials vault (Argon2id + XChaCha20-Poly1305), Touch ID / Windows Hello gate, optional Vaultwarden.
- Tasks on 1–16 hosts, triggers, workspaces.
- Imports: OpenSSH config, PuTTY, `.rdp`, RDCMan, mRemoteNG, CSV (no passwords).
- Sandboxed, signed plugins. Official: Proxmox VE, VMware ESXi/vCenter, PostgreSQL.
- Offline: no account, no telemetry.

## Known limits

- Unsigned builds; macOS and SmartScreen warn on first launch.
- Mac build is Apple silicon only.
- Not included: RD Gateway, X11 forwarding, SSHFP, VNC VeNCrypt/TLS.
- The Tauri front end (`ui-tauri/`) is not shipped.

## Verify

```bash
shasum -a 256 -c SHA256SUMS
```
